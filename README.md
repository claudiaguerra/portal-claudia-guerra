# Portal Cláudia Guerra

## Sobre o projeto

O **Portal Cláudia Guerra** é uma plataforma digital institucional, informativa e participativa criada para apresentar a trajetória, os compromissos, as propostas e as ações de Cláudia Guerra.

O projeto combina comunicação institucional, produção de conteúdo, participação cidadã e, em períodos eleitorais, uma camada de comunicação de campanha, preservando uma identidade digital permanente.

Este repositório contém a documentação, arquitetura e especificações necessárias para o desenvolvimento, implementação e evolução do Portal.
